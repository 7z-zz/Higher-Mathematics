# 高等数学证明整理规范

本文件用于公式、定理的证明和具体证明题的解释、整理与检查。全库共用维护、来源读取、文件保护、检查与修订边界、增量合并、通用格式和交付要求遵守根目录的 `AGENTS.md`；讲解深度、原理联系、方法迁移与简洁要求遵守 `.agents/Solve_AGENTS.md`，本文件补充证明专用的逻辑要求；公式速查页仍遵守 `.agents/Lib_AGENTS.md`。文中项目路径均相对于 vault 根目录，不相对于 `.agents/`。本规范以当前专升本学习范围为准，帮助读者理解为什么选择某种方法，并能在复习时自行重建证明。

## 一、任务范围与触发

- 处理证明任务时读取本文件；需要写入或调整笔记格式时再读 `Template/ProofExample.md`。仅解释或检查数学内容时不必读取样章。样章展示内容密度，不要求每篇笔记使用全部标题，也不限制必要的数学条件。
- 是否写入和修订已有文件，按 `AGENTS.md` 的任务入口与检查边界执行。
- 默认提供一种符合当前学习阶段的完整证明，其他原理视角优先用简短联系说明。是否展开多解按 `.agents/Solve_AGENTS.md` 的取舍规则；竞赛方法只在用户指定时处理并标明范围。
- 对用户指定的命题给出完整证明，压缩仅针对重复计算和未请求的扩展内容，不能省略必要论证；批量整理习题按主文件约定归纳共同方法，不默认逐题建立答案库。

## 二、处理流程

核对命题与来源 → 分清已知和待证 → 识别结构与选择方法 → 写出证明 → 检查逻辑和条件 → 提炼方法迁移 → 按主题增量归档。

1. 核对命题与来源。按主文件的读取与来源规则定位本次材料，保留原符号；重点检查命题是否完整，条件或公式不清楚时标记具体位置，不补造命题。
2. 分清已知和待证。列清变量范围、量词、区间、参数限制和目标。说明关键条件在证明中起什么作用，不擅自增加连续、可导、可积等假设。
3. 识别结构与选择方法。从目标所对应的定义或定理入手，说明题目中的哪些特征支持所选方法。使用辅助函数、变量替换或恒等变形时，解释它如何连接已知条件与目标；不用空泛口诀代替理由，也不罗列无关方法。
4. 写出证明。给出可独立阅读的完整论证，交代所取对象的范围、关键推理及依据。保留决定思路的步骤，压缩重复代数计算；最后明确回到原待证结论。
5. 检查逻辑和条件。集中按下文检查，本次草稿中的错误直接修正；已有文件遵守主文件的检查与修订边界。无法确认时保留具体疑点，继续整理可确认的部分，不把不完整论证写成已证结论。
6. 提炼方法迁移。简述下次如何从题目特征重新想到关键构造或定理，并指出适用条件和失效情形。复习路线可与方法提炼合并，不重复列举已写清的证明步骤；推广命题须另核对前提并给出依据。
7. 按主题增量归档。仅在用户要求写入时，按主文件的增量维护规则及下文归档位置执行；仅检查时报告结果。

## 三、笔记内容与讲解深度

可按“命题与条件、方法选择、标准证明、原理联系与方法迁移、来源”组织。易错点和复习路线按需要并入相关段落，不要求单独设节；复杂证明仅在必要时使用三级标题。参考样章展示可选内容，不能因栏目齐全而重复解释。

- 命题与条件：明确什么是已知、什么需要证明，解释有歧义的术语，例如严格递增与不减。条件缺失时不能静默补充后当成原命题；可确认的条件补充须明确标为补充后的命题。
- 思路分析：提供面向学习的解法说明，突出决定性观察。先说明目标需要什么，再说明现有条件如何提供它；辅助对象或关键变形应解释为何能满足目标定理的前提，不重复叙述每一步计算。
- 标准证明：逻辑自足，不能依赖读者从思路段或图像中补齐缺失步骤。定理名称和本题满足的前提应在使用处明确。
- 原理联系与方法提炼：解释决定性步骤所依赖的数学机制，提炼可复用的题目特征、操作方法和适用范围。若联系更一般的命题，须给出条件及独立依据，不把特殊情形直接推广到一般情况；与主解重复的另证优先压缩为简短联系。
- 易错点与复习路线：只保留当前题目的关键风险。反例用于否定命题或说明条件必要性，须核对它满足所讨论的条件且确实违反结论；不为装饰而添加反例或计算例题。
- 来源：按主文件要求记录；只读到已有笔记时标为转引，不能声称已核对其原始教材或截图。模型补充的证明、解释或限制不能冒充教材原文。

## 四、逻辑与数学检查

- 检查量词与对象范围。“任意”不能用几个特殊值代替；存在性、唯一性和任意性分别论证。区分充分条件、必要条件和充要条件，需要双向证明时不能只证一个方向。
- 检查定义和定理的前提。连续、可导、可积不能互相替代；区间是否开闭、端点是否包含、参数是否允许退化，都要与所用定理一致。
- 检查变形是否合法。约分前确认因子非零；取对数确认真数及底数；平方、开方、反函数变换确认符号、主值范围及是否等价；不等式乘除未知符号的量时先判断符号或分类讨论。
- 区分正向推导与等价变形。倒推可用于寻找思路，正式证明必须补齐正向论证或证明各步等价；不能从待证结论出发得到真命题就声称原命题成立。
- 检查循环论证。不得以待证结论或依赖它的公式为依据。特别是证明基础极限时，使用导数、洛必达或一般幂函数公式前核对其依据是否依赖该极限；不能确认独立性时选择可确认的基础方法，或标记依赖关系待核对。
- 检查等号、端点、分段边界及结论范围。严格与非严格不等式不能混用；涉及等号成立条件时单独核对；局部性质不能未经证明推广到整个定义域。
- 区分恒等式、极限和等价无穷小。等价关系写明趋近条件，涉及商时说明分母非零；发生主项相消时不能逐项等价替换。极限证明须交代使用连续性或极限运算法则的依据。
- 数值验证、图像和直觉只辅助理解，不能代替一般证明。命题错误时指出问题并在可确认时给出反例；条件不足、材料不清或证明无法完成时，明确缺口，不强行给出结论。

## 五、归档与格式

- 具体证明题及定理证明优先合并到 `高数常见解法/证明题/` 下的同主题笔记；公式证明沿用 `高数常见解法/证明题/公式的证明/`。用户指定文件优先，不因名称或题号不同创建重复笔记。
- 同一结论尽量在一个主题页完整维护。公式速查页保持简洁，完整证明放在证明笔记；只有确有需要、用户授权涉及相关页面且目标存在时添加链接，不为了配对而修改公式页。
- 通用格式、链接核对、增量维护与交付遵守 `AGENTS.md`，不按样章批量改写旧笔记；本专项重点核对证明完整性及第四节的逻辑与数学条件。
