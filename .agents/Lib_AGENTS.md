# 高等数学公式库规范

本文件用于公式提取、速查整理和 `高数常见解法/公式/` 内的主题维护。全库共用维护、来源读取、检查与修订边界及文件保护遵守根目录的 `AGENTS.md`；本文件只细化公式库格式，不替代其他类型笔记的规则。文中项目路径均相对于 vault 根目录，不相对于 `.agents/`。

## 一、内容范围

默认只输出：一级知识分类、二级公式分类、编号公式、必要条件和极短注释。优先级：数学正确 → 条件完整 → 便于查找 → 文字简短。

- 按知识系列拆成独立文件，不按题号、对话顺序或解题过程归档。
- 同一系列的恒等式、运算法则、重要极限和等价无穷小放在同一文件。例如三角恒等式与三角函数等价无穷小均归入 `三角函数.md`。
- 跨系列的等价替换规则、无穷小阶数比较单独归档；不把具体的三角、指数、对数等价式全部重复放进去。
- 提取材料中的公式、恒等变形、一般结论和可复用计算技巧。默认不补齐整本公式大全，只补全必要条件、符号和能可靠确认的缺失部分。
- 保留已有正确且与主题相关的条目；删除完全重复或只有符号名称差异的重复表达。具有独立使用价值的不同形式可以并列，例如二倍角的几种常用形式。
- 用户要求讲解、证明、推导或例题时，只展开指定内容；未要求改写公式库时在聊天中回答，需要保存时写入对应学习笔记，不把整份速查页扩成讲义。

## 二、格式与样章

需要写入或调整笔记格式时，读取 `Template/FormulaExample.md`，参考其简洁程度；仅解释或检查数学内容时不必读取样章。样章演示排版，不要求逐字复制，也不限制新材料中必须保留的数学条件。

- 文件名表示知识系列，一级标题表示系列内的知识类别，二级标题表示公式类型。例如 `三角函数.md` → “三角函数公式” → “三角恒等式／和角公式／二倍角公式”。
- 每个二级分类从 1 重新编号；无需二级分类时在一级标题下编号。禁止三级及更深标题，不为每条公式单独建标题。
- 分类名直接说明公式类型，不使用“怎么理解”“为什么使用”等教学标题。只有一个简单类别时无需强行拆分。
- 简短公式使用行内数学 `$...$`，一条一行。长公式、分段函数和紧密相关的公式组使用 `$$...$$`，在编号条目下正确缩进。
- 名称、条件或用途跟随条目；共用条件放在分类标题下，例如“以下均在 $x\to0$ 时成立，角度使用弧度制”，不逐条重复。
- 注释通常至多一句、约 20 个汉字；完整数学条件不受字数限制。
- 用途只保留触发特征或操作，例如“根式相减时有理化”“主项相消时先变形”。技巧优先写成恒等式、等价式或一般结论。
- 默认不使用表格、callout、emoji、大量加粗、双向链接或 YAML。已有必要链接可保留；只有当前任务确需引用其他主题时才添加已验证链接。

正文不写开场介绍、学习目标、来源叙述、复习建议、教学长段落、证明、推导、完整解题过程、具体练习答案或重复解释公式的文字。影响使用的易错点只保留一句准确限制。

## 三、归档与增量更新

默认目录：`高数常见解法/公式/`。目前已有系列文件：

- `三角函数.md`
- `指数与对数.md`
- `幂函数与根式.md`
- `多项式.md`
- `无穷小比较与等价替换.md`
- `函数极限法则.md`

这是定位提示，实际以目标文件是否存在为准。新材料优先合并到已有系列；只有出现新的独立主题才创建新文件，不创建空分类或空文件。

1. 读取本次材料与目标系列文件；只在目标目录直接文件名或当前主题内查重，不扫描全库。
2. 逐项判断所属分类，保留已有正确内容，将新条目插入对应位置；同分类重新连续编号，不全文追加。
3. 合并重复时保留完整的必要条件。若条件不同，核对是否为特殊情形，不直接当作重复删除。
4. 无法辨认或条件无法确认时，在相关分类附近用 Markdown 注释标记“待核对”及定位信息，不将猜测写成正式编号公式；交付时说明疑点。
5. 用户要求拆分综合资料时，生成相应系列文件并保留原资料，除非明确要求修改或迁移原文件。
6. 再次处理同一材料且没有实质新增时保持文件不变，不为了显示工作量调整措辞或编号。

公式库不录入来源栏目、来源叙述、来源文件及章节页码，也不以 Markdown 注释隐藏来源。本次编辑页面中的纯来源注释可去掉；必要条件、内容说明和有用链接仍须保留。无法确认的公式只保留“待核对”及必要定位信息，不因去掉来源而将猜测写成正式结论。

## 四、数学与输出检查

- 条件必须覆盖定义域、分母非零、偶次根号、对数真数与底数、反三角函数主值范围、参数限制及分段边界。
- 恒等式 $=$、等价关系 $\sim$、极限和近似不能混写。无穷小等价式要标明趋近条件；加减及主项相消时不能逐项直接替换。
- 重要极限注明趋近方向、角度单位和必要参数条件；求导与积分公式保留适用区间、所需前提和积分常数。
- 化简后仍保留原定义域限制。例如 $\sec x\cos x=1$ 必须注明 $\cos x\ne0$。
- 核对上下标、正负号、不等号、函数名、分母与根号范围、积分上下限和极限方向；数学表达式不使用反引号。
- 只写标准 LaTeX，不包含 Latex Suite 触发词或其他插件专属语法。
- 一次集中检查：分类是否合理、是否重复、编号是否连续、条件是否遗漏、是否误留来源说明、是否混入不必要讲解、例题或推导。本次草稿中的错误直接修正；已有文件遵守 `AGENTS.md` 的检查与修订边界。

完成后只报告创建或修改的文件、公式范围、重要修正和待核对项；没有变化就如实说明，不在聊天中再次全文输出。
